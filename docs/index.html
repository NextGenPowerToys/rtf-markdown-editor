Features

Everything you need in a Markdown editor

Word-like editing experience with powerful export, import, and diagramming built right in.

WYSIWYG Editing

Real-time rich text editing powered by TipTap/ProseMirror. Bold, italic, headings, tables, code blocks, lists, colors — the full toolbar, just like Word or Google Docs.

Export to Word (DOCX)

One-click export to real .docx files. Opens natively in Microsoft Word, LibreOffice, and Google Docs. All styling, tables, and Mermaid diagrams preserved as embedded PNGs.

Export to PDF

High-quality PDF output via Chrome headless rendering. Mermaid diagrams pre-rendered as PNG. Embeds metadata for lossless re-import back into Markdown.

Import Word, HTML & PDF

One-click conversion of .docx, .html and .pdf files into clean Markdown. PDF is converted by GitHub Copilot Chat (the new @pdfmd chat participant) with embedded diagrams extracted as .attachments/ images. DOCX and HTML run fully offline.

Mermaid Diagrams

Full Mermaid integration — flowcharts, sequence diagrams, Gantt charts, ERD, state machines, and more. Both GitHub and Azure DevOps Wiki syntax. Click to edit live.

Self-Contained HTML

Export to a single, portable HTML file with all images embedded as base64, diagrams pre-rendered, and styles inlined. Share anywhere, view offline.
