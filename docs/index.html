Why RTF Markdown Editor?

Markdown is the lingua franca of modern engineering and AI workflows — it diffs cleanly, it travels cleanly, and every LLM speaks it natively. But writing and reviewing it in a plain text editor is friction your team can't keep absorbing. RTF Markdown Editor gives you a WYSIWYG canvas, real RTL, and one-click round-trips to Word, PDF, and HTML — without leaving Markdown.

📝

WYSIWYG editing

Real-time rich text editing powered by TipTap / ProseMirror. Bold, italic, headings, tables, code blocks, lists, colors, alignment — the full toolbar, just like Word or Google Docs.

🌐

RTL / Hebrew / Arabic first

Smart per-paragraph direction detection. Mix Arabic / Hebrew / Urdu prose with English code in the same document — every line keeps the correct direction. Direction preserved in every export.

🔄

Manual cursor-direction toggle

Ctrl/Cmd+Shift+X cycles the current block through auto → LTR → RTL → auto. Pick a direction in an empty paragraph before you start typing.

📊

Mermaid diagrams

Full Mermaid support — flowcharts, sequence, gantt, class, state, ER, journey, pie. Both ```` ```mermaid ```` and Azure DevOps Wiki ::: mermaid syntax. Click any diagram to open it in the Mermaid NG — Visual Editor drag-and-drop WYSIWYG canvas (or the built-in source-edit modal as silent fallback).

🤖

AI PDF → Markdown

Right-click a .pdf → converts to Markdown via GitHub Copilot Chat and the bundled @pdfmd participant. Local text extraction with pdfjs-dist; embedded images saved as real .attachments/ files.

📄

Word (DOCX) round-trip

Export to a real .docx that opens natively in Word, LibreOffice, and Google Docs. Mermaid diagrams embedded as PNGs, RTL preserved. Right-click any .docx to import back into Markdown.

🖨️

PDF export

High-quality PDF rendering via Chromium headless. Mermaid pre-rendered to PNG. RTL preserved. Embeds metadata so the original Markdown structure can be re-imported.

📦

Self-contained HTML export

A single portable .html file — images embedded as base64, Mermaid as PNG, styles inlined, no CDN. Share it anywhere, view it offline.

📥

HTML → Markdown

Right-click any .html / .htm file (Confluence export, scraped docs, web archive) → convert to clean Markdown. Fully offline.

📁

Documents side panel

A dedicated Activity Bar view listing every .md / .pdf / .docx / .html in your workspace. Type-specific one-click actions: edit or convert.

💾

Event-driven autosave

Saves on blur, tab-hidden, and panel close — not on every keystroke, so embedded images don't flicker mid-typing. Content hashing prevents redundant writes.

🔒

Mostly offline · zero telemetry

Editing, autosave, exports, Word / HTML import — all run with no network. Only the AI PDF → Markdown command talks to a remote service (Copilot Chat) and only when you ask for it.

First-class RTL — not an afterthought

Most Markdown editors break the moment a sentence starts with a Latin word but is actually 95% Hebrew, Arabic, or Urdu. We don't do that. Direction is decided per paragraph, from content — not from the first character.

React אין כמו ספרייה טובה לכתוב ממשקים יפים.
כתיבה מימין לשמאל, עם תמיכה מלאה בדו-כיווניות.
  • ✓ Auto-detects Hebrew, Arabic, Persian & Urdu — sets dir per paragraph from content.
  • ✓ Not first-character based — a sentence starting with React followed by Hebrew/Arabic still flows RTL.
  • ✓ Smart paste from ChatGPT / Claude / Gemini — every line is re-evaluated, mixed-language chat output keeps its structure.
  • ✓ Manual cursor toggle — Ctrl/Cmd+Shift+X cycles the active block: auto → LTR → RTL → auto.
  • ✓ Global RTL toggle — flips the whole document when you want it.
  • ✓ RTL preserved in every export — Word (w:bidi), HTML, and PDF all render with the correct direction.
  • ✓ Code stays LTR — inline code and code blocks always render left-to-right, following programming conventions.
  • ✓ AI PDF import with Hebrew handling — text + positions are extracted locally, the model gets reading order correct.

Install

Free on the VS Code Marketplace, or install the .vsix directly from GitHub.

From the VS Code Marketplace

# Inside VS Code Quick Open (Cmd/Ctrl+P)
ext install NGPowerToys.rtf-markdown-editor

Or click Install from Marketplace.

From a GitHub release

# Download the latest .vsix
curl -LO https://github.com/NextGenPowerToys/rtf-markdown-editor/releases/latest/download/rtf-markdown-editor.vsix

# Install it into VS Code
code --install-extension rtf-markdown-editor.vsix

For development

Clone the repo, run npm install and npm run build, then press F5 in VS Code to launch an Extension Development Host. 

git clone https://github.com/NextGenPowerToys/rtf-markdown-editor.git
cd rtf-markdown-editor
npm install
npm run build

Getting started

Three ways to start editing.

📂

Open an existing Markdown file

Right-click any .md / .markdown file in the Explorer → Edit with RTF Markdown Editor. Or click the RTFMD icon that appears in the editor title bar when a Markdown file is open in another editor.

🗂️

Browse the Documents side panel

Click the RTFMD icon in the Activity Bar to see every .md, .pdf, .docx, and .html file in your workspace. Single-click any entry to edit (Markdown) or convert (everything else).

🤖

Convert a PDF with Copilot

With GitHub Copilot Chat installed, right-click any .pdf → Convert PDF to Markdown. Text is extracted locally; embedded images become real .attachments/ files; the result opens in the editor.
